Half-Life Counter-Strike 1.5 Server Windows
Edition: Non-Steam (historical WON/LAN server).

Keep this extracted folder together. Start here:

Half-Life Counter-Strike 1.5 Server Windows
  1. Setup.cmd          Install and configure the server (English yes/no wizard).
  2. Start-Server.cmd   Start the server in its console.
     Start-Panel.cmd    Open the English/German control panel instead.
                       Requires Python 3.10 or newer.
  3. Join with your compatible CS 1.5 client using HLSW or LAN Games.

Half-Life Counter-Strike 1.5 Server Linux (separate linux-mint-server package)
  Download the Linux branch ZIP or Linux release from the repository.
  First install the dependencies in that package's docs/linux-mint.md.
  1. bash setup-linux.sh
  2. bash start-server.sh
     bash start-panel.sh   Open the local browser control panel instead.

The default installation is CS15Server on Windows, CS15Server-Linux on Linux.
For another location:
  Windows: Start-Server.cmd -ServerDirectory "D:\YourServer"
           Start-Panel.cmd -ServerDirectory "D:\YourServer"
  Linux:   bash Start-Server.sh /path/to/server
           bash Start-Panel.sh /path/to/server

Configure-Server.html opened directly is a read-only preview.
Use Start-Panel to save settings, drag-and-drop the mapcycle, manage AMX,
RCON and YaPB access, and start/stop the local server. Stop before saving.

First setup downloads verified original components. Game/server binaries
and private credentials are not included in the source download.
Private credentials are generated during setup: see the installed
server's ADMIN.local.txt. Never publish that file or your configured server.

Full instructions and verification status: README.md, docs/.
