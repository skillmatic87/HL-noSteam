How it works

Run start-panel.cmd and select the installed CS15Serverfolder containing cstrike. On Linux, select the folder containing Start-CS15.sh.

Edit settings, review changes and save. The local helper handles file access and backs up affected files first.

Stop the server using the button above before saving. You can start it again here afterwards.
